Esercizi: PHP e Database - CRUD con MariaDB

Obiettivi della Scheda

  • Configurare la connessione PHP a MariaDB
  • Eseguire query sicure con prepared statement
  • Implementare operazioni CREATE, READ, UPDATE, DELETE
  • Gestire validazione server-side e messaggi di esito
  • Organizzare pagine PHP in stile didattico (una responsabilita per file)

📌 Indicazioni generali

  • PHP 5.6+
  • MariaDB 10+
  • Estensione mysqli attiva
  • Database creato con lo script: sql/esercizi_crud_mariadb.sql
  • Ogni esercizio puo essere svolto in un file PHP separato, seguendo la struttura suggerita.
  • Usa sempre prepared statement nelle query SQL.
  • Mostra messaggi chiari di successo o errore all'utente.

🧪 Snippet base query SQL (mysqli)

Query di lettura (SELECT)

<?php
require_once dirname(__FILE__) . '/../config/connessione.php';

$sql = "SELECT id, nome, cognome, email FROM studenti ORDER BY cognome, nome";
$result = $conn->query($sql);

if (!$result) {
  die('Errore nella query di lettura: ' . $conn->error);
}

while ($row = $result->fetch_assoc()) {
  echo htmlspecialchars($row['cognome']) . ' ' . htmlspecialchars($row['nome']) . ' - ';
  echo htmlspecialchars($row['email']) . '<br>';
}
?>

Query di inserimento/aggiornamento (INSERT/UPDATE)

<?php
require_once dirname(__FILE__) . '/../config/connessione.php';

// Esempio INSERT
$sqlInsert = "INSERT INTO studenti (nome, cognome, email, classe) VALUES (?, ?, ?, ?)";
$stmtInsert = $conn->prepare($sqlInsert);

$nome = 'Mario';
$cognome = 'Rossi';
$email = 'mario.rossi@studenti.it';
$classe = '4A';

$stmtInsert->bind_param('ssss', $nome, $cognome, $email, $classe);
$stmtInsert->execute();

// Esempio UPDATE
$sqlUpdate = "UPDATE studenti SET email = ?, classe = ? WHERE id = ?";
$stmtUpdate = $conn->prepare($sqlUpdate);

$nuovaEmail = 'mario.rossi2@studenti.it';
$nuovaClasse = '4B';
$idStudente = 1;

$stmtUpdate->bind_param('ssi', $nuovaEmail, $nuovaClasse, $idStudente);
$stmtUpdate->execute();

if ($stmtUpdate->affected_rows > 0) {
  echo 'Record aggiornato con successo';
} else {
  echo 'Nessuna riga aggiornata';
}
?>

✅ Regole didattiche

  • Usa sempre prepared statement ($stmt = $conn->prepare(...)).
  • Valida i dati in PHP prima della query.
  • Mostra messaggi chiari: successo, errore, campi obbligatori mancanti.
  • Per pagine di modifica/eliminazione, usa id passato via GET.
  • Niente framework e niente ORM in questa scheda.

🎯 Esercizi CREATE (Inserimento)

Esercizio C1: Inserimento Studente

File: crud_db/studenti/aggiungi.php

Consegna:
1. Crea una form POST con campi: nome, cognome, email, data_nascita, classe.
2. Verifica che nome, cognome, email siano compilati.
3. Valida il formato email con filter_var(..., FILTER_VALIDATE_EMAIL).
4. Esegui INSERT su tabella studenti con prepared statement.
5. Mostra messaggio Studente aggiunto con successo.

SQL obiettivo:

INSERT INTO studenti (nome, cognome, email, data_nascita, classe)
VALUES (?, ?, ?, ?, ?)

Esercizio C2: Inserimento Corso

File: crud_db/corsi/aggiungi.php

Consegna:
1. Crea form con campi: titolo, codice, descrizione, ore_totali, docente_id.
2. Verifica che titolo, codice, ore_totali siano obbligatori.
3. Controlla che ore_totali sia numero > 0.
4. Inserisci in corsi con prepared statement.
5. Se codice esiste gia (UNIQUE), mostra un errore leggibile.

SQL obiettivo:

INSERT INTO corsi (titolo, codice, descrizione, ore_totali, docente_id)
VALUES (?, ?, ?, ?, ?)

Esercizio C3: Inserimento Iscrizione

File: crud_db/iscrizioni/aggiungi.php

Consegna:
1. Crea una form con studente_id, corso_id, stato.
2. Le opzioni studente_id e corso_id devono essere <select> popolate dal DB.
3. Inserisci in tabella iscrizioni usando prepared statement.
4. Imposta data_iscrizione automaticamente (CURDATE()).
5. Gestisci il caso duplicato (UNIQUE studente_id + corso_id).

SQL obiettivo:

INSERT INTO iscrizioni (studente_id, corso_id, data_iscrizione, stato)
VALUES (?, ?, CURDATE(), ?)

🎯 Esercizi READ (Lettura)

Esercizio R1: Lista Studenti con Ricerca

File: crud_db/studenti/lista.php

Consegna:
1. Mostra tutti gli studenti in una tabella HTML.
2. Aggiungi campo ricerca q (GET) su nome/cognome/email.
3. Se q e presente, filtra con WHERE nome LIKE ? OR cognome LIKE ? OR email LIKE ?.
4. Mostra il totale risultati trovati.
5. Ordina per cognome ASC, nome ASC.

Esercizio R2: Lista Corsi con Nome Docente (JOIN)

File: crud_db/corsi/lista.php

Consegna:
1. Mostra elenco corsi con colonne: titolo, codice, ore_totali, docente.
2. Usa LEFT JOIN tra corsi e docenti.
3. Se non c'e docente associato, mostra Non assegnato.
4. Aggiungi filtro GET per docente_id.
5. Ordina per titolo.

SQL di riferimento:

SELECT c.id, c.titolo, c.codice, c.ore_totali,
       CONCAT(d.nome, ' ', d.cognome) AS docente
FROM corsi c
LEFT JOIN docenti d ON c.docente_id = d.id
ORDER BY c.titolo

Esercizio R3: Dettaglio Iscrizioni Studente

File: crud_db/iscrizioni/lista.php

Consegna:
1. Ricevi studente_id via GET.
2. Mostra dati dello studente (nome, cognome, classe).
3. Sotto, mostra l'elenco dei corsi a cui e iscritto con stato e voto.
4. Usa JOIN tra iscrizioni, studenti, corsi.
5. Se non ha iscrizioni, mostra messaggio dedicato.

🎯 Esercizi UPDATE (Modifica)

Esercizio U1: Modifica Email e Classe Studente

File: crud_db/studenti/modifica.php?id=...

Consegna:
1. Carica il record studente con id da GET.
2. Precompila una form con dati attuali.
3. Permetti la modifica di email e classe.
4. Valida email e aggiorna con prepared statement.
5. Mostra Modifica completata e link alla lista.

SQL obiettivo:

UPDATE studenti
SET email = ?, classe = ?
WHERE id = ?

Esercizio U2: Modifica Docente di un Corso

File: crud_db/corsi/modifica.php?id=...

Consegna:
1. Carica il corso selezionato tramite id.
2. Mostra select docenti popolata dal DB.
3. Aggiorna il campo docente_id.
4. Gestisci il caso docente_id nullo (nessuna assegnazione).
5. Mostra conferma e riepilogo corso aggiornato.

Esercizio U3: Aggiorna Stato e Voto Iscrizione

File: crud_db/iscrizioni/modifica.php?id=...

Consegna:
1. Carica una iscrizione per id.
2. Form con stato (attiva, completata, ritirata) e voto_finale.
3. Se stato completata, voto_finale deve essere tra 18 e 30.
4. Se stato diverso da completata, salva voto_finale = NULL.
5. Aggiorna il record e mostra messaggio finale.

🎯 Esercizi DELETE (Eliminazione)

Esercizio D1: Elimina Studente con Conferma

File: crud_db/studenti/elimina.php?id=...

Consegna:
1. Mostra i dati principali dello studente da eliminare.
2. Chiedi conferma con form POST (conferma=si).
3. Esegui DELETE solo se confermato.
4. Se lo studente ha iscrizioni collegate, mostra errore leggibile.
5. Reindirizza a lista.php con messaggio in query string.

Esercizio D2: Elimina Corso solo se senza Iscrizioni

File: crud_db/corsi/elimina.php?id=...

Consegna:
1. Prima della delete, conta le iscrizioni del corso.
2. Se count > 0, blocca eliminazione e mostra messaggio.
3. Se count = 0, elimina il corso.
4. Registra l'esito in un messaggio HTML chiaro.
5. Inserisci link Torna alla lista corsi.

Esercizio D3: Cancellazione Iscrizione

File: crud_db/iscrizioni/elimina.php?id=...

Consegna:
1. Carica iscrizione con nome studente e titolo corso (JOIN).
2. Mostra pagina di conferma.
3. Alla conferma POST, esegui DELETE FROM iscrizioni WHERE id = ?.
4. Torna alla lista iscrizioni mantenendo il filtro studente (se presente).
5. Mostra conferma Iscrizione eliminata.

✅ Criteri di Valutazione (rubrica sintetica)

  • Correttezza SQL (query giuste e sicure)
  • Uso corretto di GET e POST
  • Validazione lato server
  • Gestione errori DB leggibile per l'utente
  • Chiarezza e organizzazione del codice

⚠️ Errori comuni da evitare

  • Query concatenate con input utente (SQL injection)
  • Mancata validazione dell'id da GET
  • Mancato controllo di affected_rows dopo UPDATE/DELETE
  • Nessuna gestione del caso record non trovato
  • Nessun controllo sui vincoli di integrita referenziale
