Esercizi: Form HTML (solo Front-end)

📚 Riepilogo: tag HTML da utilizzare

Di seguito trovi i principali tag da usare negli esercizi della scheda:

Struttura base della pagina

  • <form>: contenitore principale del modulo.
  • <fieldset>: raggruppa campi correlati.
  • <legend>: titolo del gruppo di campi dentro fieldset.

Etichette e campi di input

  • <label>: etichetta descrittiva collegata al campo tramite attributo for.
  • <input type="text">: inserimento di testo breve (nome, cognome, oggetto).
  • <input type="email">: email con validazione nativa del formato.
  • <input type="password">: inserimento password non visibile.
  • <input type="date">: selezione data.
  • <input type="time">: selezione ora.
  • <input type="number">: valori numerici con min e max.
  • <input type="tel">: numero telefonico (eventualmente con pattern).
  • <input type="radio">: scelta singola tra opzioni alternative.
  • <input type="checkbox">: scelta multipla o conferma (es. privacy).
  • <input type="range">: selezione di un valore in un intervallo.

Selezioni e testo esteso

  • <select>: menu a tendina.
  • <option>: singola voce all'interno di select.
  • <textarea>: campo di testo multilinea (note, commenti, messaggi).

Azioni e supporto informativo

  • <button type="submit"> oppure <input type="submit">: invio della form.
  • <button type="reset"> oppure <input type="reset">: ripristino dei campi.
  • <small>: note informative aggiuntive.

Attributi HTML utili per la validazione nativa

  • required: rende il campo obbligatorio.
  • minlength e maxlength: impongono lunghezza minima/massima del testo.
  • min e max: limitano intervalli numerici o date/valori compatibili.
  • pattern: definisce un formato tramite espressione regolare.
  • placeholder: suggerisce un esempio di compilazione (non sostituisce la label).

Obiettivi della Scheda

  • Progettare moduli HTML semanticamente corretti
  • Usare i principali campi input (text, email, password, date, number, radio, checkbox)
  • Applicare validazione base nativa HTML (required, minlength, maxlength, min, max, pattern)
  • Organizzare form con label, fieldset, legend e pulsanti di invio/reset
  • Migliorare usabilità e accessibilità senza usare backend

📌 Regole generali

  • Non usare PHP, JavaScript o database.
  • Ogni esercizio deve essere svolto in un file .html dedicato.
  • Usa sempre:
  • <!DOCTYPE html>
  • <html lang="it">
  • <meta charset="UTF-8">
  • <meta name="viewport" content="width=device-width, initial-scale=1.0">
  • Collega ogni label al relativo input con l'attributo for.
  • Inserisci un pulsante finale Invia (e, dove richiesto, Reset).

🎯 Esercizi Pratici

Esercizio 1: Iscrizione Newsletter

Livello: ⭐ Principiante
Argomenti: form, label, input text/email, required, checkbox

Consegna:
1. Crea una pagina newsletter.html con titolo Iscrizione Newsletter.
2. Inserisci una form con i campi:
- Nome e Cognome (text, obbligatorio)
- Email (email, obbligatorio)
3. Aggiungi checkbox obbligatoria: Accetto l'informativa privacy.
4. Inserisci pulsanti Invia e Reset.
5. Sotto la form, aggiungi una breve nota informativa con tag <small>.

Esercizio 2: Registrazione Utente (solo HTML)

Livello: ⭐⭐ Intermedio
Argomenti: password, date, minlength, maxlength, validazione nativa

Consegna:
1. Crea registrazione-html.html.
2. Inserisci i campi:
- Username (text, obbligatorio, minlength="4", maxlength="20")
- Email (email, obbligatorio)
- Password (password, obbligatorio, minlength="8")
- Conferma password (password, obbligatorio)
- Data di nascita (date, obbligatorio)
3. Aggiungi una select Classe con almeno 4 opzioni (es. 1A, 2A, 3A, 4A).
4. Inserisci pulsante Crea account.
5. Non implementare controlli con JavaScript: solo attributi HTML.

Esercizio 3: Prenotazione Aula Informatica

Livello: ⭐⭐ Intermedio

- Note (textarea, facoltativo, maxlength="300")
3. Inserisci pulsante Prenota aula.
4. Raggruppa i campi in sezioni usando fieldset e legend.

Esercizio 4: Sondaggio sulle Tecnologie Web

Livello: ⭐⭐⭐ Avanzato
Argomenti: radio, checkbox, gruppi di scelta, struttura semantica

Consegna:
1. Crea sondaggio-web.html con titolo Sondaggio Tecnologie Web.
2. Inserisci una domanda a scelta singola (radio):
- Quale linguaggio preferisci? con opzioni: HTML, CSS, JavaScript, PHP.
3. Inserisci una domanda a scelta multipla (checkbox):
- Quali strumenti usi? con almeno 5 opzioni (VS Code, Git, Figma, XAMPP, Browser DevTools, ecc.).
4. Inserisci un campo range (1-10) per il livello di interesse verso il web development.
5. Aggiungi textarea finale per commenti.
6. Inserisci pulsanti Invia sondaggio e Reset.

Esercizio 5: Form Contatti Completa e Accessibile

Livello: ⭐⭐⭐ Avanzato
Argomenti: accessibilità base, ordine logico tabulazione, pattern, campi obbligatori/facoltativi

Consegna:
1. Crea contatti-accessibile.html.
2. Progetta una form contatti con i campi:
- Nome (text, obbligatorio)
- Cognome (text, obbligatorio)
- Email (email, obbligatorio)
- Telefono (tel, facoltativo, con pattern per sole cifre e simbolo + opzionale)
- Oggetto (text, obbligatorio)
- Messaggio (textarea, obbligatorio, minlength="20")
3. Inserisci checkbox: Desidero ricevere una copia del messaggio.
4. Associa correttamente tutte le etichette e usa placeholder solo come aiuto, non come sostituto della label.
5. Inserisci un blocco finale <small> con testo: I campi contrassegnati con * sono obbligatori.

✅ Criteri di valutazione

  • Struttura HTML valida e ordinata
  • Corretto uso dei tipi di input
  • Presenza dei vincoli nativi HTML richiesti
  • Chiarezza visiva e semantica della form
  • Rispetto della consegna senza uso di backend o JavaScript
